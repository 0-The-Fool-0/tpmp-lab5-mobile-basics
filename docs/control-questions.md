## Задание 2. Objective-C

1. **Какие расширения файлов у следующих типов файлов?**
   - C language source file — `.c`
   - C++ language source file — `.cpp` (также используются `.cc`, `.cxx`)
   - Header file — `.h` (в C++ также часто `.hpp`)
   - Objective-C source file — `.m`
   - Objective-C++ source file — `.mm`
   - Object (compiled) file — `.o`

2. **Способы вывода на экран в Objective-C**
   - `NSLog(...)` — стандартный способ вывода в консоль с форматированием.
   - `printf(...)` — функция из C, также доступна в Objective-C.
   - `fprintf(stdout, ...)` / `fprintf(stderr, ...)` — вывод в стандартные потоки.

## Задание 3. Массивы в Objective-C

1. **Какой метод используется для получения количества элементов в NSArray?**  
   Свойство `count`, например: `array.count`.

2. **Как правильно создать пустой mutable массив в Objective-C?**  
   Корректные варианты:
   - `NSMutableArray *array = [[NSMutableArray alloc] init];`  
   - `NSMutableArray *array = [NSMutableArray array];`

3. **Какой метод используется для добавления элемента в конец mutable массива?**  
   `addObject:`

4. **Что произойдет при попытке получить доступ к элементу массива по индексу, превышающему размер массива?**  
   Возникнет ошибка времени выполнения (`NSRangeException`, out-of-bounds).

5. **Как получить последний элемент массива?**  
   Для `NSArray` можно использовать `lastObject`.

## Задание 4. Swift REPL / Playground / swiftc

1. **Что такое Swift REPL и в каких случаях рекомендуется использовать?**  
   Swift REPL (Read-Eval-Print Loop) — интерактивная консоль Swift, где код выполняется построчно. Удобно для быстрых экспериментов, проверки маленьких фрагментов логики и обучения.

2. **Что такое Playground? Какие задачи можно создавать в Playground?**  
   Playground — интерактивная среда для Swift (в Xcode/Swift Playgrounds), где сразу видно результат выполнения кода. Подходит для обучения, прототипирования алгоритмов, тестирования идей и демонстрации работы API без полноценного проекта.

3. **Как компилировать приложение на Swift в консоли bash?**  
   Через `swiftc`:
   ```bash
   swiftc main.swift -o app
   ./app
   ```

## Задание 6. Словари и xCode/Swift

1. **Расскажите о режимах работы среды программирования xCode.**  
   Основные режимы: редактирование кода (Editor), сборка и запуск (Run), отладка (Debug), тестирование (Test), профилирование (Profile/Instruments), архивирование (Archive) и работа с симулятором/устройством.

2. **В чем отличия языка Swift от C и C++?**  
   Swift безопаснее по памяти (опционалы, строгая типизация), современнее синтаксически, имеет ARC, мощные коллекции и функциональные конструкции. В C/C++ больше ручного контроля низкого уровня, но выше риск ошибок управления памятью.

3. **Какие способы отладки программ поддерживает xCode?**  
   Точки останова (breakpoints), пошаговое выполнение (step into/over/out), просмотр переменных, LLDB-консоль, watch expressions, backtrace, Instruments для анализа производительности.

4. **Какие операторы языка Swift вы знаете?**  
   Арифметические (`+ - * / %`), сравнения (`== != > < >= <=`), логические (`&& || !`), присваивание (`=`), диапазоны (`...`, `..<`), nil-coalescing (`??`), тернарный оператор (`?:`), приведение типов (`as`, `as?`, `as!`).

5. **Какие типы коллекций применяются в Swift и в чем их особенности?**  
   - `Array` — упорядоченная коллекция элементов одного типа.
   - `Set` — неупорядоченная коллекция уникальных элементов.
   - `Dictionary` — пары ключ-значение с уникальными ключами.

6. **Какие типы проектов xCode вы знаете?**  
   iOS/macOS/watchOS/tvOS приложения, консольные приложения (Command Line Tool), frameworks/libraries, Swift Package, тестовые target’ы (Unit/UI tests), playground.

## Задание 7. Массивы, опционалы, классы в Swift

1. **Как создать пустой массив типа Int в Swift?**  
   `var numbers: [Int] = []`  
   или `var numbers = [Int]()`

2. **Что произойдет, если объявить массив как константу (`let`) и попытаться изменить его размер?**  
   Будет ошибка компиляции: константный массив нельзя изменять (добавлять/удалять элементы).

3. **Какой метод используется для добавления элемента в конец массива?**  
   `append(_:)`

4. **Какой тип данных должен быть у всех элементов массива?**  
   Один и тот же тип (или совместимый с объявленным типом массива).

5. **Что означает “массив является универсальной коллекцией”?**  
   Массив подходит для большинства типовых задач хранения последовательности данных: доступ по индексу, перебор, добавление, удаление, сортировка, фильтрация.

6. **Какой метод используется для перебора элементов массива с получением индекса?**  
   `enumerated()`, например:
   ```swift
   for (index, value) in array.enumerated() {
       print(index, value)
   }
   ```
