## Примечание для отчета

1. Запусти каждую программу и сделай скрин консоли для каждого теста.
2. При необходимости в столбце "Действительные выходные данные" оставь ровно тот текст, который выдала программа на твоем запуске.
3. Если хотя бы один тест не совпадет с ожидаемым результатом, пометь "Нет", исправь программу и перезаполни строку.
