# TPMP Lab 5 — Mobile programming basics

Objective-C and Swift exercises: factorials, arrays, integer conditions, dictionary processing and MVC string processing.

## Technologies and layout
`task2`–`task7/` contain independent exercises; `docs/` contains control questions and a protocol. Objective-C, Swift, SwiftPM.

## Build and run
For SwiftPM exercises use Swift 5.9+: `cd task6 && swift run` and `cd task7 && swift run`. Compile task4 via `swiftc main.swift -o task4` from `task4/`. Objective-C requires Xcode/macOS.
