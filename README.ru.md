# Лабораторная работа ТПМП 5 — основы мобильной разработки

Учебные задачи на Objective-C и Swift: факториалы, массивы, условия для числа, обработка словарей и MVC-обработка строк.

## Технологии и структура

- `task2`–`task7/` — отдельные задания;
- `docs/` — контрольные вопросы и протокол;
- Objective-C, Swift, Swift Package Manager.

## Сборка и запуск

Для Swift-пакетов нужен Swift 5.9 или новее:

```sh
cd task6 && swift run
cd task7 && swift run
```

Задание 4 можно собрать из его каталога командой `swiftc main.swift -o task4`. Для заданий Objective-C требуется Xcode/macOS.
